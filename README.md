# creatix

Creatix Interiors main website.

## Preview locally (beginner-friendly)

You can view the website on your own computer in just a few steps.

### 1) Open a terminal or command prompt
- **Windows:** Press the **Windows** key, type **Command Prompt**, and open it.
- **Mac:** Press **Command + Space**, type **Terminal**, and open it.
- **Linux:** Open **Terminal** from your applications menu.

### 2) Go to the project folder
Type the command below, then press **Enter**:
```bash
cd /path/to/creatix
```
Replace `/path/to/creatix` with the actual folder where this project is saved.

### 3) Start a simple local web server
Type this command and press **Enter**:
```bash
python -m http.server 8000
```
If that command fails, try this instead:
```bash
python3 -m http.server 8000
```

### 4) Open the site in your browser
Open your browser and go to:
```
http://localhost:8000
```

### 5) Stop the server when you’re done
Go back to the terminal window and press **Ctrl + C**.
